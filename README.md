# MySQL and MongoDB Student Lab

Интернэт орчны программчлалын лабораторийн ажил.

## using
- MySQL
- MongoDB Atlas
- Node.js
- Express.js
- HTML, JavaScript

## functions
- Оюутнуудын жагсаалт харах (GET)
- Шинэ оюутан нэмэх (POST)
- MySQL болон MongoDB өгөгдлийн сантай холбогдох

node --env-file=.env server-mysql.js

MongoDB сервер:
node --env-file=.env server-mongo.js
